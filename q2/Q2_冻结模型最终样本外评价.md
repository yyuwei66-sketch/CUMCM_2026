# Q2 冻结模型最终样本外评价

## 1. 冻结模型

在联合搜索、逐参数 Profile 稳定性分析和 May–Aug 分月鲁棒性检查后，冻结以下模型：

- W = 60
- K_L = 3
- K_P = 2
- Load history = lag1
- PV history = lag1 + lag7 + mean7
- Load calendar = weekday7
- PV calendar = annual1
- α_L = 0.3
- α_P = 10
- 残差场景窗口 = 28 天

概率区间采用滚动对称共形校准。仅在 May–Aug 开发期比较 M ∈ {14,28,42,60}，以 80%/90% 覆盖率对名义覆盖率的总偏差作为主要选择指标，最终冻结：

- conformal score window M = 14 天

## 2. 开发期概率校准

May–Aug 基础场景区间：
- 80% coverage = 72.62%
- 90% coverage = 82.77%

M=14 校准后：
- 80% coverage = 80.00%
- 90% coverage = 89.91%
- CRPS = 199.312 kW
- 80% width = 885.424 kW
- 90% width = 1159.274 kW

## 3. Sep–Dec 冻结模型样本外评价

### 点预测

- Load MAE = 115.260 kW
- Load RMSE = 155.679 kW
- PV MAE = 123.461 kW
- PV RMSE = 251.251 kW
- Net Load MAE = **201.897 kW**
- Net Load RMSE = **298.367 kW**

### 概率预测：未校准场景

- CRPS = 145.848 kW
- 80% coverage = 76.59%
- 90% coverage = 85.85%
- 80% width = 620.447 kW
- 90% width = 784.795 kW

### 概率预测：M=14 滚动共形校准

- CRPS = **145.848 kW**
- 80% coverage = **80.54%**
- 90% coverage = **90.16%**
- 80% width = 674.068 kW
- 90% width = 886.018 kW

共形校准只调整区间边界，不改变场景分布本身，因此 CRPS 在校准前后保持不变。

## 4. 结果解释

基础场景区间存在明显欠覆盖：
- 80% 区间实际覆盖率仅 76.59%
- 90% 区间实际覆盖率仅 85.85%

经过 M=14 滚动共形校准后：
- 80% coverage 提升至 80.54%
- 90% coverage 提升至 90.16%

与名义 80%/90% 水平非常接近。

区间宽度相应从：
- 80%: 620.4 → 674.1 kW
- 90%: 784.8 → 886.0 kW

说明校准通过适度扩大区间修复了欠覆盖。

## 5. 关于“独立测试”的表述

Sep–Dec 在项目早期探索阶段曾被查看过旧模型表现，因此严格统计意义上不能再称为“完全从未接触的 pristine holdout”。

本轮可以准确表述为：

> 最终冻结模型的参数选择与稳定性检查均仅基于 May–Aug 开发区间，Sep–Dec 未参与本轮冻结参数的选择，并用于冻结模型的样本外评价。

不建议写成“Sep–Dec 从未用于任何前期分析”。

## 6. 最终可用于后续策略层的预测配置

后续风险分位数策略统一使用：

W=60, K_L=3, K_P=2,
h_L=lag1,
h_P=lag1+lag7+mean7,
Load calendar=weekday7,
PV calendar=annual1,
α_L=0.3,
α_P=10,
28日成对残差场景。

若策略需要完整分位数分布 p05–p95，应直接从原始场景经验分布取分位数；M=14 共形校准仅用于报告 80%/90% 覆盖区间，不应机械外推为完整 CDF 的所有分位数。
