# Q2 联合网格搜索与逐参数 Profile 稳定性分析

## 1. 实验设计

本轮不使用 Sep–Dec 独立测试集。所有参数选择与稳定性分析统一在公共验证区 **2025-05-01 至 2025-08-31** 完成，以保证 W=30/60/90/120 均拥有完整历史窗口。

候选空间：

- W ∈ {30, 60, 90, 120}
- K_L ∈ {1, 2, 3, 4, 5}
- K_P ∈ {1, 2, 3, 4}
- h_L, h_P ∈ {lag1, lag1+lag7, lag1+lag7+mean7, lag1+lag7+mean7+trend7}
- Load calendar ∈ {fri_sat, weekday7, fri_sat+annual1, fri_sat+annual2}
- PV calendar ∈ {annual1, annual2, weekday7+annual1, weekday7+annual2}
- α_L, α_P ∈ {0.1, 0.3, 1, 3, 10, 30, 100}

每个 W 下评估 560 个 Load 配置 × 448 个 PV 配置 = 250,880 个组合；四个 W 合计约 **1,003,520 个联合组合**。

## 2. 当前公共验证区全局最优

- W = 60
- K_L = 3
- K_P = 2
- h_L = H0_lag1
- h_P = H2_lag1_lag7_mean7
- Load calendar = weekday7
- PV calendar = annual1
- α_L = 0.3
- α_P = 10.0
- Validation Net RMSE = **392.623 kW**

这是公共验证区最优，不是最终测试结果；Sep–Dec 尚未参与本轮选择。

## 3. Profile 定义

对任一超参数 θ_j 的候选值 v，定义：

Profile_j(v) = min_{θ_-j} RMSE_net(v, θ_-j)。

即固定当前参数为 v，其余参数全部重新优化。这样同时检验：
1. 固定该参数后最优性能下降多少；
2. 其余最优参数是否发生结构性变化。

## 4. W 的结论

W=60 的 RMSE 最低。相对 W=60：
- W=30：+1.823%
- W=90：+0.510%
- W=120：+0.080%

因此 **60–120 天形成明显性能平台**。W=60 数值最优，但 W=120 仅差约 0.08%，说明窗口并不存在非常尖锐的唯一最优点。

## 5. 主要稳定性结论

- K_L：K=2/3/4/5 的最佳可达性能十分接近；K=1 明显不足。
- K_P：K=2 最优，K=4 几乎等价；K=1 明显较差。
- h_L：四种历史状态的 profile 差异均小于约 0.6%，Load 历史结构较稳健。
- h_P：H2 最优，但 H0/H3 也很接近；仅 H1 明显差一些。
- Load calendar：四种候选差异很小，weekday7 数值最佳。
- PV calendar：annual1/annual2 接近；叠加 weekday7 会明显恶化。
- α_L：0.1–1 处于低误差平台；30/100 的过强正则明显恶化。
- α_P：1–10 处于低误差平台；过小或过大均会变差。
- W=120 可以通过完全不同的一组参数达到与 W=60 几乎相同的 RMSE，说明**预测性能稳定，但最佳超参数存在较强可替代性**。

## 6. 当前模型结构

当前公共验证区最优：

W=60, K_L=3, K_P=2,
h_L=lag1,
h_P=lag1+lag7+mean7,
Load calendar=weekday7,
PV calendar=annual1,
α_L=0.3,
α_P=10.

在建模组确认候选空间后，再冻结模型并首次打开 Sep–Dec 独立测试集。风险分位数策略 Notebook 也应在冻结后的模型参数上重建。
