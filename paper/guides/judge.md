# 高教社杯数据分析类建模论文评审准则

> 版本：v3.0（阶段—可见性校准版）  
> 更新：2026-08-04  
> 用途：以后评价高教社杯全国大学生数学建模竞赛的数据分析类论文时，默认使用本文件。它是依据公开获奖论文、同题低奖对照、官方评阅规范和赛题讲评建立的工作量表，不是组委会公开的百分制，也不是未经条件说明的获奖概率模型。

## 0. 使用本准则时先记住三句话

1. **论文竞争力不等于最终奖项。** 最终结果还受赛区推荐名额、国一/国二申请轨道、学校上限、答辩和合规复核影响。
2. **评委可能看见的缺陷不等于技术审计能发现的全部缺陷。** 两者都要报告，但不能混成一个分数。
3. **高奖首先奖励完整、贴题、可见、可核对的三天解答。** 方法复杂、图表多、术语新都不能替代这一点。

如果用户只给出一篇论文而没有说明阶段，默认进入“修稿模式”：给论文竞争信号、技术可靠性和条件式奖档，不伪装成能够确定最终官方奖项。

## 1. 必须同时回答的三个问题

### 1.1 CRS：竞赛论文评阅分

`CRS`（Competition Review Score，0—100）衡量一名正常阅读论文及常规支撑材料的竞赛评委，能够看见的高奖信号。它关注逐问交付、题意结构、结果证据、主线、可读性和可见验证。

CRS 的前身是 v2.0 的 OAS。改名是为了避免把工作量表误解成官方分数或概率。

### 1.2 TRS：技术可靠性分

`TRS`（Technical Reliability Score，0—100）衡量数据、推断、预测、优化和代码是否真正可信。它包括代码阅读、复算和复现后才会发现的深层问题。

允许且必须诚实报告 `CRS 高、TRS 低`。2025 C 官方展示论文中已出现论文可见信号很强、但代码层验证流程存在严重风险的实例；官方奖项不能被当作技术正确性的金标准。

### 1.3 APA：奖项路径判断

`APA`（Award Path Assessment）不是第三个加总分，而是根据评审阶段给出的条件式判断：

| 阶段 | 已知信息 | 可以回答什么 |
|---|---|---|
| S0 全体参赛 | 赛区、题目、参赛组别 | 省奖竞争力；不能套用全国送审基率 |
| S1 赛区获奖/候选 | 省奖结果、是否可能推荐 | 送全国竞争力；推荐结果仍受名额与学校上限影响 |
| S2 全国送审 | 已确认推荐及国一/国二申请轨道 | 在对应轨道内判断国一/国二/未获全国奖风险 |
| S3 答辩/复核后 | 论文评阅、答辩和合规信息 | 才能对最终奖项作相对完整判断 |

若阶段、申请轨道或赛区信息未知，必须输出条件分支或弃权，不能把 CRS 直接翻译成唯一奖项。

## 2. 证据边界与已知校准范围

本准则经历三轮演化：

1. **正样本召回：**2015—2025 年 32 篇优秀/展示论文。最初学术型标准把 26/32 篇低估，说明三天竞赛不能按期刊审稿主次评价。
2. **低奖特异性：**加入 2020、2022 等年份的国二、省一和区间标签论文，形成决定性结构门与真实验证审计。
3. **阶段—可见性校准：**加入 2025 C 同题国一、国二、省一梯度和命题人讲评。发现强省一可在论文层面优于国二，而官方国一仍可能有隐藏代码泄漏；因此最终标签必须按阶段解释，论文可见分与技术审计必须分开。

限制：

- 公开低奖/未获奖终稿仍少，且存在作者上传的自选择偏差；
- 全国名单通常没有题号，作者仓库奖项多为 B 级而非官方逐篇配对；
- 现有样本不能支持精确概率、全体百分位或固定跨年阈值；
- 2023—2025 材料权重最高，2020—2022 次之，2019 及以前主要用于检验长期不变量；
- 当年题面、规则和讲评优先于本文通用条款。

## 3. 开始评分前：建立并冻结题前评阅要点表

评分者在读论文正文、奖项标签和官方赛后讲评之前，必须根据题面和数据说明填写：

| 项目 | 内容 |
|---|---|
| 逐问硬交付 | 每个动作词要求的数值、区间、名单、预测、规则、方案或检验 |
| 决定性结构 | 最多 1—3 个一旦忽略就会改变对象、距离、标签、概率、可行域或时点含义的结构 |
| 无效捷径 | 看似常见但不能回答本题的做法 |
| 主张最低证据 | 描述、预测、因果、决策各自至少需要什么证据 |
| 必见结果载体 | 评委应能找到的关键表、图、方案或对象清单 |
| 合规版本 | 竞赛年份对应的匿名、页数、AI 披露、程序和附件要求 |
| 冻结信息 | 创建时间、版本、是否已看官方讲评；正式校准时记录文件哈希 |

官方赛后讲评可用于揭示后的误差分析，但不得伪称为事前发现。若根据讲评修改题前表，必须形成新版本，并用另一个隐藏题目年验证。

### 3.1 常见决定性结构

| 结构 | 线索 | 忽略后的典型后果 |
|---|---|---|
| 重复/分组主体 | 同一患者、企业、站点、文物多条记录 | 伪增样本量、标准误过小、训练测试主体泄漏 |
| 时间和事件顺序 | 预测未来、首次发生、政策前后 | 偷看未来、错误删失、把观测时间当事件时间 |
| 区间/左/右删失 | 事件发生在两次观测之间、首次即发生、始终未发生 | 达标时间和风险函数失真 |
| 成分/比例闭合 | 分量和固定、占比、配比 | 普通距离和相关失真，非法扰动离开单纯形 |
| 检出限与选择 | 未检出、0、只观测成功样本 | 标签、缺失和尾部分布被改变 |
| 空间/网络依赖 | 路网、河网、相邻区域、传播 | 把相关节点当独立，切分泄漏 |
| 守恒与可行域 | 容量、质量、流量、库存、信号配时 | 优化方案或敏感性样本不可执行 |
| 小样本高维不平衡 | 少数类很少、特征多于样本 | 选择/调参泄漏，总体准确率掩盖失败 |

不要求命中某个方法名称。混合模型、按主体聚合、GEE 或其他充分论证的方法都可能处理重复测量；评审的是结构是否被实质解决。

## 4. 三层可见性：模拟官方对齐而不牺牲技术诚实

每个证据或缺陷标注一个可见性等级：

| 等级 | 评审材料 | 典型内容 | 主要影响 |
|---|---|---|---|
| V0 前台 | 摘要、目录、各问结论、主要表图 | 漏题、摘要无数字、结果矛盾、约束外方案 | CRS 强影响，TRS 视性质影响 |
| V1 正文 | 完整方法、数据处理、验证描述、普通附录 | 独立性假设、错误事件定义、明显不当切分 | CRS 与 TRS 都影响 |
| V2 审计 | 源代码细读、运行、复算、文件一致性 | 折外预处理、全量训练后伪交叉验证、代码与正文不一致 | TRS 和审计风险为主 |

### 4.1 可见性处理原则

- CRS 依据 V0/V1 证据评分；V2 隐藏问题原则上不反向改写“评委实际可见信号”。
- 若当年规则明确要求程序与正文一致，V2 问题另设合规/复核风险；一旦官方复核发现，可能直接改变奖项。
- V2 严重错误必须在首屏报告，不能因为“评委可能忽略”而淡化。
- 若代码逻辑已经在正文中明确写出，属于 V1，不得降格为隐藏问题。

另设 `ARF`（Audit Risk Flag）：

- `绿色`：已检查关键代码/计算，未发现改变主结论的错误；
- `黄色`：代码未提供、未运行或存在材料不一致，结论仍有实质不确定性；
- `红色`：发现泄漏、循环标签、伪造验证、不可运行或正文—代码冲突，足以使核心结论失效。

材料未审计时不能标绿色。

## 5. 合规闸门：按竞赛年份版本化

合规不混入 CRS 普通加总。评审开始必须确认竞赛年份；若用户未说明，可以暂按最新公开规则检查，但必须写明是假设。

至少核对：

- 匿名信息；
- 摘要、目录、正文页数和格式；
- 必交论文、程序、数据和支撑材料；
- AI 工具披露要求；
- 引用、外部链接和可识别信息；
- 程序能否运行、结果与正文是否匹配；
- 相似度、抄袭、伪造和其他取消资格风险。

状态：

| 状态 | 含义 | 奖项处理 |
|---|---|---|
| C0 | 已核对且未见问题 | 继续评分 |
| C1 | 材料或当年规则不足 | 继续条件式评分，降低置信度 |
| C2 | 有明确风险但未确认达到取消条件 | 置顶警告，不武断宣称违规 |
| C3 | 有充分证据符合当年取消/不予评奖条件 | 输出“可能不予评奖/需官方核实”，不得用 CRS 掩盖 |

当前参考：[2025 年 AI 使用规定](https://www.mcm.edu.cn/html_cn/node/eebcfb6dc37fd2de9603dc16026fdf01.html)、[2026 年论文格式规范](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html)。未来年份必须重新核验。

## 6. CRS：竞赛论文评阅分（100 分）

为避免仅凭少量新样本频繁漂移，v3.0 保留 v2.0 八维权重；变化在于按 V0/V1 证据评分、按阶段解释。

| 维度 | 分值 | 核心问题 |
|---|---:|---|
| A. 逐问覆盖与直接回答 | 24 | 每个关键问是否交付了题面要求的最终答案？ |
| B. 数据与决定性结构 | 16 | 是否识别并实质处理了会改变问题含义的数据结构？ |
| C. 模型适配与主线连贯 | 18 | 方法是否服务题面动作，各问输入输出是否形成主线？ |
| D. 具体结果与证据可见性 | 17 | 数字、区间、名单、方案和对比是否可定位、可核对？ |
| E. 可见验证与主张一致性 | 11 | 正文中的验证是否匹配主要主张，摘要是否诚实反映最强证据？ |
| F. 摘要、结构与可扫读性 | 8 | 评委能否快速理解做了什么、得到什么、证据在哪？ |
| G. 现实解释与可执行性 | 4 | 输出是否变成对象级规则、时点、方案、建议并说明边界？ |
| H. 创新与额外洞见 | 2 | 非模板化处理是否真正改善答案？ |
| **合计** | **100** | |

### 6.1 A：逐问覆盖与直接回答（0—24）

- `20—24`：全部关键问和子问有可定位直接答案；摘要、正文、结论基本一致。
- `16—19`：总体完成，一处关键子问部分回答或答案位置较散。
- `8—15`：至少一个关键问主要只有方法，没有最终结果。
- `0—7`：漏答多个关键问或论文主线错位。

模型、流程图和分析过程不等于交付。逐问矩阵必须写出论文真正给出的数值、区间、名单、规则或方案。

### 6.2 B：数据与决定性结构（0—16）

- `14—16`：对象、单位、缺失、重复、时间/空间对齐和样本组织处理有针对性；决定性结构从数据到结论始终被尊重。
- `10—13`：主结构基本处理，但一处划分、删失、阈值、可行域或来源交代不足。
- `5—9`：清洗模板化，结构处理含糊或只写关键词，可能影响核心结论。
- `0—4`：对象、标签、单位、时间或主体组织错误，使主要答案无意义。

“标准化、删除异常值、SMOTE、归一化到 100%”都不是天然正确的加分项。先问它们是否必要、是否改变题面含义。

### 6.3 C：模型适配与主线连贯（0—18）

- `15—18`：每个模型职责清楚，尊重结构，上一问输出自然进入下一问，最终形成统一答案。
- `11—14`：总体合题，但参数、假设、局部结构或衔接有可修补缺口。
- `6—10`：模型名多、职责弱，或模型评价指标没有回答题目动作。
- `0—5`：核心模型不能回答题目，推理链或优化闭环断裂。

经典方法不因简单扣分，深度学习不因复杂加分。官方 2025 C 讲评明确批评了用普通聚类或纯机器学习替代统计优化和异常判定。

### 6.4 D：具体结果与证据可见性（0—17）

- `14—17`：每个关键问有数值、区间、对象表、策略表或清晰图形，结论旁有证据和必要基线。
- `10—13`：主要结果具体，少数问题只定性或证据距离结论较远。
- `5—9`：大量“效果良好”，最终数字/方案不全，关键结果藏在代码或难定位附录。
- `0—4`：没有可核对输出，或表、图、正文互相矛盾到无法确定答案。

表图数量不计分；只有压缩信息并支撑决策的表图计分。

### 6.5 E：可见验证与主张一致性（0—11）

- `9—11`：主要主张有风险匹配的样本外/主体外/时间外验证、残差诊断、基线、合法扰动或不确定性分析；摘要采用最相关的证据。
- `6—8`：至少一条核心主张有有效验证，但覆盖、独立性或解释有限。
- `2—5`：主要是样本内拟合、单次小测试、循环验证或孤立漂亮指标；仍有少量可用证据。
- `0—1`：无有效验证，或正文已经足以判断验证泄漏/循环，且主要性能结论失效。

必须把摘要/结论中的最强数字与正文最独立、最相关的证据交叉核对。例如摘要只报交叉验证 AUC 0.96，而正文独立测试 AUC 0.62，应标为可见主张冲突，不能按 0.96 加分。

### 6.6 F：摘要、结构与可扫读性（0—8）

- `7—8`：摘要按问题顺序给方法、关键数字和结论；正文层级、表图编号和交叉引用清楚。
- `5—6`：主线可复述，但摘要数字不足、结果较散或有小冲突。
- `2—4`：摘要罗列模型，正文很难定位答案。
- `0—1`：结构混乱或摘要与正文严重冲突。

前台扫描只是检验信息可见性，不代表官方评委只看 90 秒。

### 6.7 G：现实解释与可执行性（0—4）

- `4`：输出完整转成对象级判断、时点、额度、规则、方案，并说明适用边界。
- `2—3`：建议可执行，但对象、条件或边界不够具体。
- `1`：泛化建议，与模型输出联系弱。
- `0`：没有现实解释，或建议违反模型约束。

### 6.8 H：创新与额外洞见（0—2）

- `2`：非模板化处理确实改善数据使用、验证、决策或解释。
- `1`：有合理改进，但贡献有限或证据不足。
- `0`：方法常规；这本身不构成大缺陷。

赛区规范另有“突出创新例外推荐”通道。若论文综合分不高但有真正突破，单独标记 `创新例外候选`，不得用 H 的 2 分假装已经解决其他缺陷。

## 7. 高奖资格门、硬限制与防重复扣分

### 7.1 四道论文可见资格门

| 门 | 通过条件 | 失败处理 |
|---|---|---|
| 关键交付门 | 所有关键问题有直接结果 | 不得预测强国一；按漏答封顶 |
| 决定性结构门 | 识别并实质处理题目核心结构，或充分说明普通方法仍适用 | 系统失败原则上封顶 79；局部失败封顶 83 |
| 可见主张一致性门 | 摘要、结论、正文最强证据同口径，无明显挑指标和自相矛盾 | 核心冲突原则上封顶 79；主答案失效可至 74/69 |
| 结果可见门 | 关键数字、对象、区间或方案能在正文快速定位 | 通常下降一个竞争档 |

预测强国一论文信号前，四门必须逐项通过。门只评价 V0/V1 证据；V2 隐藏问题通过 ARF 和 TRS 报告。

### 7.2 硬限制

| 缺陷 | CRS 处理 |
|---|---|
| 一个关键问题无最终结果 | 原则上不高于 77；次要子问可放宽 |
| 两个及以上关键问题无最终结果 | 原则上不高于 69 |
| 核心对象、标签、单位或时间含义用错，主要答案无效 | 原则上不高于 69 |
| 正文可判断核心预测存在泄漏/循环，主要性能失效 | 原则上不高于 74 |
| 系统忽略决定性结构但仍保留部分描述价值 | 原则上不高于 79 |
| 优化结果违反自己的约束或不可行域 | 影响主答案时按无效答案，通常不高于 69—74 |
| 摘要与正文关键数字明显冲突 | E 主扣；影响主答案时触发一致性门 |
| 关键结果只在代码、正文无法定位 | D 主扣并通常降一个竞争档 |
| 无敏感性分析、无创新、公式少、图少 | 不设统一封顶，按题目是否依赖它判断 |

### 7.3 缺陷台账：同一问题只在 CRS 中主扣一次

| 缺陷 ID | 可核对事实 | 位置 | 可见性 | CRS 主归属 | 下游后果 | 门/封顶 | TRS 影响 |
|---|---|---|---|---|---|---|---|
| D01 |  | 页/节/代码 | V0/V1/V2 | A—H 中一个或“仅 TRS” | 只说明，不再扣 |  |  |

规则：

- 同一缺陷只能在 CRS 的一个维度作为主扣分；
- 封顶改变最终报告分，不在原始分上再次机械减分；
- TRS 是另一测量对象，可以独立反映同一技术错误；
- 不要把重复测量错误在 B、C、E、门和硬限制中连续扣五次。

## 8. CRS 的解释：先说论文信号，再说奖项路径

| CRS | 历史论文竞争信号 |
|---:|---|
| 88—100 | 强国一论文信号；仍须四门通过 |
| 84—87 | 国一/国二候选论文信号 |
| 80—83 | 全国奖论文信号或极强省一；单凭分数不能定国一/国二 |
| 74—79 | 国二/强省一信号 |
| 68—73 | 国二与省一重叠区 |
| 60—67 | 省级奖竞争信号 |
| 0—59 | 低奖或不获奖风险较高 |

这些区间只描述论文信号，不是最终奖项映射。2025 C 同题复评中，一篇省一因论文完成度高得到封顶后 83，高于已知国二 77；这与赛区推荐标签被删失并不矛盾。

### 8.1 同题相对比较优先

当有同年同题样本时，必须增加配对判断：

1. 谁更完整直接回答题面？
2. 谁处理了该题真正的决定性结构？
3. 谁的核心结果更具体、证据更邻近？
4. 谁有正文可见的硬矛盾或无效验证？
5. 谁在摘要和结论中更诚实地呈现最强证据？

少于 5 篇同题样本时，不给伪百分位，只给顺序和不确定性。跨年份的绝对分差不自动解释为奖项差。

### 8.2 奖项路径固定输出

| 条件 | 判断 |
|---|---|
| 若处于 S0 | 省奖竞争信号：___；赛区未知因素：___ |
| 若已省一但推荐未知 | 论文层全国奖信号：___；是否送全国不可由论文反推 |
| 若为全国国一申请 | 在同题国一申请池中的相对位置：___；国一/降国二/未获风险：___ |
| 若为全国国二申请 | 国二/未获风险：___；原则上不把升国一作为常规分支 |
| 若需答辩 | 另列答辩可验证点、代码/数据复核风险和表达风险 |

2024、2025 年所有送全国论文中最终获得任一全国奖的粗比例均约 74.5%，但它混合组别和轨道，只能说明条件基率变化，不能直接作为某篇论文的概率。

## 9. TRS：技术可靠性分（100 分）

| 维度 | 分值 | 核心审查 |
|---|---:|---|
| 数据完整性与泄漏控制 | 25 | 来源、标签、清洗、重复主体、切分、时间顺序、代码数据一致性 |
| 统计有效性与可识别性 | 20 | 样本量、混杂、标准误、多重检验、删失、因果措辞 |
| 验证与泛化 | 20 | 正确切分单位、折内预处理、独立测试、基线、校准、误差分布 |
| 假设、参数与模型适用性 | 15 | 假设能否成立，参数是否有依据，模型是否匹配数据结构 |
| 稳健性与不确定性 | 10 | 阈值、权重、噪声、随机性、外推和情景变化是否翻转结论 |
| 可复现性与审计性 | 10 | 字段、参数、随机种子、程序、环境、结果是否足够复核 |
| **合计** | **100** | |

解释：

- `85—100`：主要结论技术可靠；
- `70—84`：总体可用，有局部假设或验证缺口；
- `55—69`：结论脆弱，需要重做关键验证；
- `0—54`：至少一条核心结论可能失效。

严重泄漏、循环标签、伪外层交叉验证、重复主体跨训练测试、非法外推和约束外优化，必须在首屏明确写出，不能只藏在扣分表里。

## 10. 主张—证据矩阵：验证必须匹配任务

先把每个核心结论标成 `描述 / 预测 / 因果 / 决策`，再检查相应证据。

| 任务/结构 | 最低可信证据 | 常见伪验证 |
|---|---|---|
| 描述性关系/回归 | 效应方向与量级、标准误/区间、残差或替代模型；重复主体需分组处理 | 只报 p 值、把特征重要性叫显著性 |
| 重复测量 | 混合效应/GEE/主体聚合或充分替代；按主体重采样/切分 | 删除主体 ID 后按记录随机切分 |
| 分类/预测 | 切分先于插补、选择、标准化和增强；正确切分单位；独立测试；不平衡指标与基线 | SMOTE 后再交叉验证、只报总体准确率 |
| 时间序列 | 时间外滚动/固定截止日验证；特征不看未来 | 随机 K 折、全序列平滑后切分 |
| 首次事件/达标时间 | 明确主体、事件与删失；必要时处理区间/左/右删失 | 把首次观测到事件的时间当真实事件时间 |
| 聚类/分组 | 稳定性、可解释差异及对下游答案的真实贡献 | 用轮廓系数证明分组能优化决策 |
| 优化/策略 | 目标与现实风险对应；约束可行；有基线、权重/参数敏感性 | 输出违反约束；只展示算法收敛 |
| 因果结论 | 识别假设、混杂路径、替代解释和稳健性 | 用相关系数、SHAP 或预测精度证明因果 |
| 成分/比例 | 保持闭合结构的模型、距离和扰动 | 各分量独立加噪、普通欧氏距离无说明 |
| 空间/网络 | 空间/图结构建模或分块验证 | 相邻节点随机拆分到训练测试 |

每条最强主张填写：

| 主张 | 类型 | 正文最强证据 | 独立性 | 口径一致 | 状态 |
|---|---|---|---|---|---|
|  | 描述/预测/因果/决策 | 页码、表图、指标 | 是/部分/否 | 是/否 | 支持/有限/冲突/缺失 |

## 11. 标准评审流程

### 第一步：上下文卡

记录竞赛年份、题号、组别、赛区、当前阶段、全国申请轨道、是否答辩、材料完整度。未知项必须显式写“未知”。

### 第二步：当年合规检查

给出 C0—C3 状态和证据，不凭最新规则处罚旧年份。

### 第三步：冻结题前评阅要点表

只基于题面和字段说明建立硬交付、决定性结构、无效捷径和最低验证。

### 第四步：V0 前台扫描

只看摘要、目录/结构、各问结论和主要表图，记录：

- 每问是否出现；
- 是否有具体答案；
- 最强数字是什么；
- 最显眼矛盾是什么；
- 主线能否用两句话复述。

此时不定最终分。

### 第五步：V1 逐问证据审计

| 题目要求 | 硬交付 | 论文直接答案 | 证据位置 | 完成状态 | 主要风险 |
|---|---|---|---|---|---|
| 问题一 |  |  | 页/节/表图 | 完成/部分/缺失 |  |

### 第六步：结构和主线审计

| 决定性结构 | 题面/字段线索 | 忽略后果 | 论文处理 | 门状态 |
|---|---|---|---|---|
|  |  |  | 页/公式/代码 | 通过/部分/失败 |

再写出：

> 原始数据 → 处理/特征 → 模型 → 中间结果 → 后续问题输入 → 最终答案

任何断点必须进入缺陷台账。

### 第七步：主张—证据核对

把摘要和结论中的最强数字与正文最独立证据比较，检查训练/测试、主体、时间、指标和样本口径。

### 第八步：先给 CRS 原始区间，再应用门和封顶

证据明确时可给点分；存在提取失败、公式缺页、参数口径不清或合理评分分歧时，给 `点估计 [下限, 上限]`。封顶只应用一次。

### 第九步：V2 技术审计并给 TRS、ARF

检查代码是否实现正文、预处理和调参是否在折内、主体是否隔离、核心表能否复算。未运行时写明“未审计”，不得把猜测当错误。

### 第十步：同题相对排序和 APA

优先与同年同题、同阶段样本配对；阶段未知则输出条件分支。

### 第十一步：按收益排序修改建议

- `P0`：合规、漏答、无效主答案、可见矛盾、违反约束；
- `P1`：评委容易看见的主要失分，如摘要无数字、结果难找、题眼未处理；
- `P2`：技术可靠性和审计风险，如正确重切分、折内流水线、稳健性；
- `P3`：文字、图表和方法精修。

优先给 3—5 项；每项写清要改什么、为何影响 CRS/TRS、应新增哪张表/图/实验。不要用“加强分析、增加创新”。

## 12. 固定输出格式

以后用本标准评一篇论文，默认按以下顺序输出。

### 12.1 首屏结论

> 模式/阶段：___；合规：C_；CRS：__ [__, __]/100，论文信号：___；TRS：__ [__, __]/100；ARF：绿/黄/红；评分证据等级：E_；奖项判断置信度：A_。最强获奖信号是___；最可能降档的可见问题是___；最严重的技术风险是___。

紧接着列：

> 关键交付门：__；决定性结构门：__；可见主张一致性门：__；结果可见门：__。原始分：__；封顶后：__；依据：__。

### 12.2 上下文与奖项路径

| 年份/题号 | 赛区 | 阶段 | 申请轨道 | 答辩 | 缺失信息 |
|---|---|---|---|---|---|

给 S0—S3 的适用条件式判断；信息不足时明确弃权于哪一步。

奖项路径必须分两行写，禁止用技术审计结果倒推常规评委一定会发现：

> **常规论文评阅预测（仅 V0/V1）：**___。
>
> **若进入代码、数据或答辩复核（加入 V2）的条件风险：**___。

### 12.3 逐问交付矩阵

使用第 11 节表格，逐问写直接答案、证据位置、完成状态和风险。

### 12.4 缺陷台账

列 3—8 个真正可能影响奖档或结论的缺陷，标 V0/V1/V2 和唯一 CRS 主归属。

### 12.7 三类评价分开写

- **评委容易奖励：**只写 V0/V1 可见优点；
- **评委容易降档：**写漏答、题意错位、结果冲突、证据难找和主线断裂；
- **可能被常规评阅忽略但技术上必须修：**写 V2 泄漏、循环、复现失败和代码不一致。

### 12.8 修改优先级

最多 3—5 项，按 P0→P2。只在有相似修订证据时估计分数变化；否则用“小/中/大”影响，不编造精确增分。

## 13. 置信度与弃权规则

### 13.1 评分证据等级

| 等级 | 条件 |
|---|---|
| E3 | 题面、完整论文、关键图表和关键支撑材料齐全；完成 V0/V1，且关键代码/计算已审计；双人复核可提高一致性，但不能替代缺失材料或 V2 审计 |
| E2 | 题面和完整论文齐全，代码未运行或少量附件缺失 |
| E1 | 论文/题面不完整、OCR 严重、关键表图缺失，只能条件式评分 |
| E0 | 只有摘要、标题或二手描述；不得给确定总分和奖档 |

### 13.2 奖项判断置信度

| 等级 | 条件 |
|---|---|
| A3 | 阶段、申请轨道、赛区和同题比较池均较清楚，标签来源可靠 |
| A2 | 阶段/轨道已知，但同题池小或赛区信息不完整 |
| A1 | 只有论文和题面；只能给历史论文信号与条件分支 |
| A0 | 题面/正文不足或合规可能取消；对奖项弃权 |

CRS 接近门槛、评分区间跨两个档、关键结构证据含糊或两名评分者分歧大时，不得给“高置信度”。

## 14. 评价语言约束

- 每个“合理、严谨、创新、稳健、效果好”必须指向页码、表图、数字或可复核逻辑。
- 不用模型数量替代质量判断；不把 XGBoost、LSTM、PSO 等名称自动视为创新。
- 不把特征重要性叫显著性，不把相关叫因果，不把训练回代叫泛化。
- 不因出现“交叉验证、敏感性、鲁棒性”标题自动给分；必须说明检验了哪条主张、数据是否独立、结果是否改变决策。
- 不因无创新、公式少、图少自动排除国一。
- 不因官方国一标签掩盖技术错误，也不因隐藏代码错误假装官方评委一定会降奖。
- 不为鼓励用户而抬分；也不为了贴历史标签而强行压低一篇高质量省一。
- 对技术错误区分“已观察”“合理推断”“材料不足”；未运行代码时不得声称已复现失败。

## 15. 最终判定原则

竞赛论文的优先顺序是：

> 当年合规 → 逐问交付 → 决定性结构 → 具体答案 → 模型主线 → 可见主张一致性 → 现实方案 → 创新与精修

技术审计的优先顺序是：

> 对象与标签 → 主体/时间隔离 → 折内预处理 → 独立验证 → 统计可识别性 → 稳健性 → 复现性

最终奖项判断的优先顺序是：

> 论文信号 → 同题相对位置 → 赛区推荐状态 → 国一/国二申请轨道 → 答辩与合规复核

如果预测低于国一，必须指出是哪一道门、哪一个硬交付、哪条可见证据或哪一阶段条件造成；不能只说“创新不足、深度不够”。如果预测强国一，也必须逐门确认，并同时报告最可能被常规评阅忽略的技术风险。

## 16. 后续校准纪律

- 新样本先用冻结量表评分，再揭示奖项；标签已知时必须明确写“标签已知、量表冻结”。
- 按整个题目年划分开发/验证/隐藏测试，禁止把同题论文随机拆到两侧。
- 优先检验同题配对排序、国一召回、同轨道国二的假国一率、门状态和弃权覆盖率。
- 双人盲评时报告加权 Kappa 和 ICC；分歧先改锚点，不用平均分掩盖。
- 只有至少两个独立题目年出现同方向系统误差，或官方规则发生变化，才修改权重/门槛。
- 便利样本不具代表性时不输出 Brier 分数、可靠性曲线或伪精确概率。
- 每次更新保留旧版、变更日志、开发集改善和隐藏测试影响。

详细方案见：[v2 现状审计](评价系统v3/现状审计.md)、[2025 C 冻结复评](评价系统v3/2025C冻结复评.md)、[校准实验设计](评价系统v3/校准实验设计.md)、[信息需求与取证优先级](评价系统v3/信息需求与取证优先级.md)。
